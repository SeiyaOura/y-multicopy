# マウス X・Y 染色体の進化地図

マウス (GRCm39) の X・Y 染色体上のタンパク質コード遺伝子について、17 種の脊椎動物との相同性・保存度・機能遺伝子の分布をマウス染色体の位置に沿って解析し、`index.html` で可視化する。

## 種パネル

| 系統 | 種 |
|---|---|
| 齧歯類 | ラット, ゴールデンハムスター, モルモット |
| 霊長類 | ヒト, チンパンジー, アカゲザル, マーモセット |
| その他の真獣類 | イヌ, ウシ, ウマ, アフリカゾウ |
| 有袋類・単孔類 | オポッサム, カモノハシ |
| 哺乳類以外 | ニワトリ, アノール, ネッタイツメガエル, ゼブラフィッシュ |

## 実行手順

```
pip install biopython
python3 fetch_xy_data.py     # NCBI Gene/Datasets + Ensembl REST (約 15 分、data/cache/ にキャッシュ)
python3 phastcons_bins.py    # UCSC mm39 phastCons35way を HTTP range で要約 (数秒)
python3 analyze_xy.py        # 解析 → data/*.tsv, data/xy_data.json
python3 build_viewer.py      # → index.html
```

## 方法

- **遺伝子**: Entrez で `10090[taxid] AND X|Y[chr] AND alive AND protein coding` (X 1144, Y 517)。うち現行 RefSeq アノテーションに位置がある X 984 + 4 (unlocalized)、Y 266 を解析した。残りの 403 は位置もアノテーションもない旧遺伝子 ID。
- **オルソログ**: NCBI Orthologs を主とし、NCBI にない種は Ensembl Compara で補った (一致度 25% 未満の遠い one2many は除外)。NCBI 由来のものは双方の最長 CDS を翻訳し、BLOSUM62・末端ギャップ無料の大域アラインメントで一致度 (一致残基 / 整列残基) を計算した。Ensembl 由来のものは Ensembl の perc_id (source/target の大きい方) を使った。
- **dN・dS**: 対ラット・対ヒト・X–Y ガメトログ間。タンパク質アラインメントでコドンを対応させ、Nei–Gojobori 法と Jukes–Cantor 補正で計算した。
- **系統層**: オルソログが見つかる最も遠い系統 (マウス特異的 → … → 脊椎動物)。
- **多コピーファミリー**: 同じ染色体上のマウスタンパク質どうしで一致度 70% 以上・被覆 50% 以上の連結成分。Yq の Sly / Ssty1 / Ssty2 / Srsy にはリポジトリの既存分類 (`../sequences/*.genes.tsv`) を使った。
- **X–Y ガメトログ**: 各 Y 遺伝子について 3-mer で X タンパク質の候補を絞り、アラインメントで最も似た X 遺伝子を選んだ (一致度 35% 以上、Y 側の被覆 50% 以上)。
- **機能**: NCBI の GO 注釈。実験的根拠コード (EXP/IDA/IMP/IGI/IPI/IEP/HTP など) があるか、生物学的プロセス名に基づく 4 区分 (生殖・神経・免疫・クロマチン/RNA)。1 Mb ウィンドウごとに、染色体全体の割合に対する集中を二項検定 (片側) で判定した。
- **phastCons**: mm39 phastCons35way の bigWig のズームレベル (2,240 bp) を HTTP range で読み、遺伝子ごと・ウィンドウごとに平均した。遺伝子間領域とイントロンも含む。

## 出力

| ファイル | 内容 |
|---|---|
| `data/genes.tsv` | 1 遺伝子 1 行: 位置, 系統層, ファミリー, GO, phastCons, 各種との一致度, dN/dS, X ガメトログ |
| `data/orthologs.tsv` | マウス遺伝子 × 種: オルソログ ID・シンボル・染色体・位置・一致度・dN・dS |
| `data/gametologs.tsv` | Y 遺伝子 → 最も似た X 遺伝子, 一致度, dN, dS |
| `data/windows.tsv` | 1 Mb ウィンドウ: 遺伝子数, 機能区分ごとの数, 多コピー, 系統層, 種ごとの平均一致度, phastCons, dN/dS |
| `index.html` | ビューア (X / Y 切替) |

## 主な結果 (X 染色体)

- **X の遺伝子内容は真獣類でほぼ保存されている (Ohno の法則)。** オルソログが X 上にある割合は、ラット 836/846、ヒト 693/705、イヌ 674/696。
- **X の 2 つの起源がはっきり分かれる。** オポッサムで X 上にあるのは 363/617 で、残りはオポッサムの常染色体 7・4 にある。前者が獣類共通の X 保存領域 (XCR)、後者は真獣類の祖先で加わった X 付加領域 (XAR)。カモノハシでは 6 番 (394/576)、ニワトリでは 4 番 (273) と 1 番 (145)、ツメガエルでは 8 番 (343) に対応する。
- **XCR は XAR より保存度が高い。** 対ヒトの一致度の中央値は XCR 90.6%、XAR 82.1%。
- **マウス X はヒト X に対して大きく再編成されている** (ドットプロット)。遺伝子の内容は同じでも、ブロックの順序と向きは入れ替わっている。
- **多コピー遺伝子 282 個 (61 ファミリー)** は、Slx/Slxl1、Btbd35f、H2al1、Ssxb、Rhox、Mage、Spin2 などのクラスターに集中する。系統層は齧歯類・マウス特異的に偏り、精巣で発現するアンプリコン領域に対応する。
- **機能遺伝子のホットスポット**: 実験的 GO をもつ遺伝子は 7–8 Mb (30 遺伝子中 22)、72–74 Mb、100 Mb 付近、133 Mb 付近に集中する。具体的な区間と p 値はビューアの第 3 節に一覧で示す。

## 主な結果 (Y 染色体)

- Y 遺伝子 266 個のうち 258 個が多コピーで、ほとんどは Yq の Ssty2 (158)、Sly (55)、Ssty1 (28) と Yp の Rbmy (9) である。
- **単一コピーのガメトログ**の X–Y 一致度: Eif2s3y 98%、Ddx3y 91%、Usp9y 84%、Uba1y 83%、Kdm5d 79%、Uty 79%、Zfy 70%、Rbmy 50%、Sry 37%。Sry–Sox3 が最も分岐しており、最古の層にあたる。
- **Yq の多コピーファミリーは X 側の対応ファミリーと対になっている。** Ssty1/2 ↔ Spin2c (一致度 58%)、Sly ↔ Slx 類 (3830403N18Rik, Gm2030, 57–64%)、Srsy ↔ Srsx (65%)。X–Y 間の遺伝子コンフリクトの結果として共に増幅したモデルと整合する。祖先遺伝子は Sly が SYCP3、Ssty が SPIN1 で、どちらもニワトリでは常染色体または Z にある。

## 注意点

- 一致度は NCBI 由来 (自前のアラインメント) と Ensembl 由来 (perc_id) で定義が少し異なる。`orthologs.tsv` の `source` 列で区別できるので、厳密な比較には NCBI 由来の行だけを使うこと。
- Y の多コピー遺伝子や X のアンプリコンは、オルソログ予測もアラインメントによる保存度も不安定。phastCons も多コピー領域では低く出やすい。
- `data/cache/` (生データと CDS、約 12 MB) はコミットしていない。`fetch_xy_data.py` で再取得できる。
